# Hickory Sands District AVA: the boundary as proposed to TTB

The boundary of the proposed Hickory Sands District American Viticultural Area (TTB Docket No. TTB-2026-0005, Notice
No. 243, 91 FR 52576) as proposed to TTB, with the changes discussed with TTB on October 15, 2026: the boundary
description, TTB's notice with the changes highlighted, a side-by-side, GIS layers, and the 13 USGS 1:24,000 quadrangles
with the boundary. Prepared by Dan McLaughlin, Robert Clay Vineyards (petitioner).

Build it with one command (macOS; it installs what it needs):

```
./build.sh
```

and find the package for TTB in `dist/`. See [BUILD.md](BUILD.md) for what the build does, the project layout, and how to
change the boundary.

Every line of the boundary is either a pin on a printed mark or junction, or a trace of the printed ink of the USGS
quads (road and creek centres, contour centres), never a copy of an existing boundary layer.
